6. TECHNICAL INCIDENT DETAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6.1 The data breach originated from misconfigured server at IP address 198.51.100.17.
    An S3-compatible object storage bucket was inadvertently set to public read access
    on 2024-01-08 at 14:32:07 UTC. The exposed data remained publicly accessible until
    2024-01-11 at 09:15:22 UTC (approximately 67 hours).

6.2 The misconfiguration was introduced via a deployment script committed by
    DevOps Engineer Oliver Schneider (username: oschneider, email: o.schneider@nexora-digital.de,
    employee ID NDS-EMP-01203). The commit hash was a7f3c2e9b1d84560efba923174c8650d2f1e48a3.

6.3 Exposure window: The following API endpoint was publicly accessible:
    https://api.nexora-digital.de/v2/users/export?format=csv

    During the exposure window, 3 distinct external IP addresses accessed the endpoint:
      - 203.0.113.45 (Germany)
      - 203.0.113.199 (Netherlands)
      - 2001:0db8:0000:0042:0000:8a2e:0370:7334 (France)

6.4 The API authentication token that was inadvertently embedded in the deployment
    script was: ghp_x8Kp3mNqRTvL7yWzJcF2dBsHnU4oAeI9V1Yw
    (This token has been revoked. Treat any occurrence of this string as sensitive.)

    An AWS access key pair was also exposed:
    Access Key ID:     AKIAIOSFODNN7EXAMPLE
    Secret Access Key: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
    (Both have been revoked.)
